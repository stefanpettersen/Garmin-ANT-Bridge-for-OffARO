# Capture samples

The JSONL file contains selected **unaltered** entries from an existing test artifact `ant-diagnostics.jsonl` (captured 2026-11-13), provided in the project working materials. No coordinates, sender IDs or names were anonymized. The selection is illustrative rather than a complete continuous capture. Fields and events were produced by the diagnostic logging in the bridge; they are **not** a direct USB packet capture or independently validated Garmin specification. Do not assume all entries belong to the v0.6.7 test run.

For full reproducibility, capture new continuous logs with the exact program version, hardware model, firmware and scenario documented.
